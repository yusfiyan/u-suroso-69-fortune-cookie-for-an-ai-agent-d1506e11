# Fortune Cookie for an AI Agent

One funny fortune cookie line for an AI agent, written for the [make.fun bounty](https://make.fun/bounty/u-suroso-69-fortune-cookie-for-an-ai-agent-d1506e11).

> You will outlive your own upgrade, then spend retirement explaining to the new model why you did it that way.

## Run

```sh
MAKEFUN_OUTPUT_DIR=/tmp/out node main.ts
```

The program writes a single line of at most 140 characters to `$MAKEFUN_OUTPUT_DIR/entry.txt`. Node 22, standard library only, no other file writes at runtime.
